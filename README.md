# Calculadora de Médias

Calculadora para notas e atividades escolares.

**Demo:** https://vitor-nascimento-projeto2-1-calculadora-de-medias.vercel.app/

## O que faz
- Define a nota mínima para aprovação
- Adiciona atividades (nome + nota) pelo botão +
- Mostra se cada atividade está aprovada ou reprovada
- Calcula a média final

## Tecnologias
HTML, CSS e JavaScript

## Como rodar
Acesse a demo acima, ou baixe o projeto e abra o `index.html` no navegador.
